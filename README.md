# 伍睿 · 个人主页

根据工作区中的简历 PDF 制作，使用原生 HTML、CSS 和 JavaScript，无构建依赖，也不依赖外部字体、CDN 或远程图片。

## 预览

直接用浏览器打开 `index.html`，或在此目录运行：

```sh
python -m http.server 5173 --bind 127.0.0.1
```

访问 http://127.0.0.1:5173 。邮箱自动复制需要浏览器的剪贴板权限；本地文件模式不可用时页面会显示手动复制提示。

## 内容与维护

- `index.html`：个人介绍、教育与实习经历、项目、技术栈和联系方式。
- `style.css`：配色、布局和手机适配。
- `script.js`：研究兴趣图形、菜单、导航状态、邮箱复制。
- `assets/portrait.jpg`：与原始简历一致的个人照片。
- `伍睿-简历.pdf`：简历下载源文件；改名时同步修改 HTML 的两个下载链接。

项目图形均为流程示意。指标来自简历，未添加虚构仓库链接或博客地址。硕士结束时间标记为预计毕业。

公开部署时上传 HTML、CSS、JS、assets 目录和简历 PDF 即可。`tmp` 是本地核验文件，不用于部署。

页面包含简历中的邮箱、电话与照片；这些内容也是发布后的公开页面内容。
